# CompTIA A+ IT Support Ticket Simulation

## Overview

This project simulates a real-world IT help desk environment based on
CompTIA A+ troubleshooting and support concepts.

The project contains a collection of simulated support tickets covering
common hardware, software, operating system, networking, and user-support
issues.

## Objectives

- Practice structured IT troubleshooting
- Apply CompTIA A+ troubleshooting methodology
- Document technical issues clearly
- Identify likely causes of problems
- Record troubleshooting steps and solutions
- Practice professional help desk communication

## Ticket Categories

The simulated tickets cover areas such as:

- Hardware
- Windows / Operating Systems
- Networking
- Printers and peripherals
- Software and applications
- Account and access issues
- Security
- Performance issues

## Troubleshooting Methodology

Each ticket follows a structured troubleshooting process:

1. Identify the problem
2. Establish a theory of probable cause
3. Test the theory
4. Establish a plan of action
5. Implement the solution
6. Verify full system functionality
7. Document findings and actions taken

## Ticket Format

Each ticket contains:

- Ticket ID
- Date
- User / department
- Issue description
- Symptoms
- Initial assessment
- Troubleshooting performed
- Root cause
- Resolution
- Verification
- User communication
- Ticket status


## Skills Demonstrated

This project demonstrates knowledge of:

- PC hardware troubleshooting

- TCP/IP and DHCP
- DNS troubleshooting
- Peripheral troubleshooting
- Basic security practices
- Command-line tools
- System diagnostics
