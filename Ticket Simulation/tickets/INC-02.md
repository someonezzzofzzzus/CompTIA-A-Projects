Issue description:  

        When the user turn on the PC, it loads normally but when user starts 
        to use the mouse, system crushes and  screen turns blue after restart

Symptoms: 

    -   System restarts
    -   Blue screen 
    -   Mouse is unresponded

Assesment/Troubleshooting:

    -   Inspect and disconnect the mouse (Does shows any lights and signs of power connectivity)
    -   Try to substitute the device with a working one
    -   Substitution resolved the problem with blue screen(It does not crush when old mouse was disconnected)
        but new device does not respond either 

Possible causes:

    -   The USB port might be faulty
    -   Drivers for USB devices could be installed wrongly or conflict with Windows system


Recommended steps:

    -   Try to a different USB port for mouse connectivity
    -   Check Device Manager if the system sees the device
    -   Use Windows Update, there maybe a conflict between device's drivers and Windows updates
    -   Reinstall/Update Mouse driver

Current Assesment: 

    Replacing the original mouse stopped the BSOD and unexpected system restarts, suggesting that 
    the original mouse may have been faulty or involved in a hardware/driver conflict.

    However, because the replacement mouse is still unresponsive, the underlying USB/driver issue 
    has not yet been fully resolved.
