Department/User: Mike-Brand [Marketing]

Priority: Medium

Issue description:  

        When the user turn on the PC, it loads normally but it works slowly.
        When demanding jobs are done by system, screen freezes

Symptoms: 

    -   System working slow
    -   Screen freezes
    -   Poor performance

Assesment/Troubleshooting:

    -   Analyze active processes 
    -   Check Task Manager for apps which starts when the system loads

Root cause:

    -   Most of the available RAM is being used by background processes
    -   There is a lot of Start Up Applications enabled in Task Manager.

Recommended steps:

    -   Disable unused applications in ["Startup Apps"]
    -   Use Windows Update 
    -   Restart the PC

Current Assesment: 
        The system performance is being affected by the high amount of RAM being
        used by background processes and unnecessary startup applications.

        Disabling unused startup applications should reduce the number of
        processes running when Windows starts and may improve the overall system
        performance.
